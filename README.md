# Deep Research Plugin for Antigravity

Autonomous multi-step deep research engine for Antigravity, modeling the recursive depth, factual rigor, and exhaustive architectural synthesis of **Gemini Deep Research**.

## Features
- **Slash Command `/deepresearch`:** Interactive entrypoint accessible from the Antigravity chat interface.
- **Recursive Multi-Stage Web Search:** Multi-hop query expansion and gap analysis.
- **Source Verification:** Cross-checks technical claims across independent documentation and code repositories.
- **Publication-Grade Synthesis:** Exhaustive technical reports with Mermaid diagrams, comparative trade-off matrices, and citation tables.

## Usage
Inside any Antigravity session, run:
```bash
/deepresearch <Topic, System, or Architecture Question>
```
